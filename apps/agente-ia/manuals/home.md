# Manual do Módulo Dashboard

O módulo **Dashboard** é a tela inicial do ERP GrindX. É a primeira tela exibida ao usuário após fazer login no sistema. Ela tem função de boas-vindas e orientação, indicando como navegar pelo ERP.

Esta tela é **estática e somente de leitura**: não permite editar dados, salvar informações ou executar operações de negócio.

## Tela de Boas-Vindas (Dashboard)

Ao acessar o ERP, o usuário vê um **cartão de boas-vindas** centralizado no meio da tela. Esse cartão contém os seguintes elementos, na ordem em que aparecem:

1. **Ícone de foguete (ícone decorativo)**
   - É apenas um símbolo visual no topo do cartão.
   - Não é clicável e não executa nenhuma ação.

2. **Título "Bem-vindo ao GrindX"**
   - Texto de saudação que identifica o sistema.
   - Não é um botão; não possui ação.

3. **Texto de orientação**
   - Mensagem: "Este é o seu novo centro de controle modular. Utilize o menu lateral ou superior para navegar entre as funcionalidades disponíveis."
   - Informa ao usuário que a navegação entre os módulos do ERP é feita pelo **menu lateral** ou pelo **menu superior**.
   - Não é um botão; não possui ação.

### Botões e elementos interativos desta tela

Esta tela **não possui botões** dentro do cartão de boas-vindas. Todos os elementos visíveis (ícone, título e texto) são informativos e não executam nenhuma ação ao serem clicados.

Para realizar qualquer ação no sistema, o usuário deve utilizar os menus de navegação do ERP (menu lateral ou menu superior), que ficam fora desta tela e dão acesso às demais funcionalidades e módulos.

### Permissões

Esta tela não exibe conteúdo restrito por permissão. Qualquer usuário autenticado que consiga acessar o ERP visualiza a tela de boas-vindas do Dashboard da mesma forma.
